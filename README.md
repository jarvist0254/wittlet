## What Wittlet Does

Wittlet is an interactive ambient companion for the Windows desktop. Enjoy conversational interactions, casual games, and interactive lessons, alongside safe, operator-approved local file automation.

### Core Capabilities

- Lightweight, floating desktop companion interface for Windows 10/11.
- Local conversational intelligence, casual games, and learning exercises.
- Operator-governed file tasks: review every proposed change before writing.
- Zero cloud recording: your conversations and desktop context stay private.
- Free to download and play with no recurring subscription fees.


---

## Pricing & Licensing

- **Model:** Free to download and use ($0 USD). Optional cosmetic Spark bundles available as one-time purchases; no recurring subscription.
- **Local Data Guarantee:** 100% local data persistence. Your records, databases, and configuration remain entirely on your device with zero mandatory cloud telemetry.
